BlueFairy API Gateway — Marketing Content
==========================================


3-SENTENCE SUMMARY
------------------

BlueFairy API Gateway sits in front of the WordPress REST API with a response cache, a per-IP rate limiter and signed outbound webhooks, all managed from one screen at Settings → API Gateway. Anonymous GET responses are served from cache with an X-BF-Cache header you can see from curl, clients over the limit get a proper 429 with Retry-After, and post, user, comment and WooCommerce order events reach your other systems as HMAC-signed JSON with a delivery log and one-click resend. Requires PHP 8.1+ and WordPress 6.6+; licensed GPL-2.0-or-later; free — add API Gateway Pro for up to 500 of everything, tag-based purges, per-key limits, DDoS blocking, automatic retries with alerts and CRM presets.

    <h3>REST Response Cache</h3>
    <p>Anonymous <code>GET</code> responses are stored and served back with <code>X-BF-Cache: HIT</code>; every response is labelled HIT, MISS or BYPASS. Logged-in and authenticated requests are never cached, and the cache purges itself when a post, term or comment changes. Uses Redis or Memcached when you have one.</p>

    <h3>Rate Limiting</h3>
    <p>A sliding-window limit per client IP — seeded at 300 requests a minute. The breaching request gets <code>429</code> with <code>Retry-After</code>; after that the client is refused for the rest of its window without touching the database. Forwarded-IP headers are trusted only from the proxies you list.</p>
  </div>

    <h3>Signed Webhooks</h3>
    <p>Post, user, comment and WooCommerce order events are sent as JSON with an <code>X-BF-Signature</code> HMAC-SHA256 over the timestamp and body, so the receiver can prove where it came from and when. HTTPS targets only; the secret is generated for you.</p>

    <h3>Delivery Log &amp; Resend</h3>
    <p>Every delivery is logged with its HTTP status and response body. A failed one can be resent from the log or straight from the dashboard. Deliveries go out after the page has been sent, so a bulk import or a dead endpoint never slows the request that triggered them.</p>
