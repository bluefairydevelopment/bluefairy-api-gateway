# Security policy

Please **do not** report security vulnerabilities in a public GitHub issue.

Email **support@bluefairydevelopment.com** with:

- the plugin name and version,
- what the problem is and how to reproduce it,
- your WordPress and PHP versions.

We acknowledge reports within two business days and will keep you updated until a fix is released. We credit reporters in the changelog unless you ask us not to.

Only the latest released version of the plugin receives security fixes.
